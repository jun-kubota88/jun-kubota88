# こんにちは、久保田淳一 です 👋

COACHTECH でフルスタックWeb開発を学習中のWeb系エンジニア志望です。
- PHP・Laravelを学習中です。API開発やWebアプリケーション開発を通して、実践的なスキルを身につけています。

## 🛠️ 使える技術

- **バックエンド**: PHP / Laravel
- **フロントエンド**: HTML5 / CSS / Blade
- **データベース**: MySQL
- **その他**: Docker / Git・GitHub
